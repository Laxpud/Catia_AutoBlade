# CATIA AutoBlade v0.2.0 internal preview

This internal preview packages the validated single-airfoil and spanwise
multi-airfoil workflows as an installable Windows wheel.

## Highlights

- explicit `create` and non-combinatorial `batch` job planning;
- CATIA session isolation, failure snapshots, and deterministic cleanup;
- external workspace initialization with immutable package examples;
- configuration discovery, schema migration preview, and backups;
- installed-wheel smoke tests, artifact content manifests, and environment
  diagnostics.

## Verified baseline

- Windows 11 x64;
- CPython 3.14.x x64;
- `pywin32` 311;
- CATIA P3 V5-6R2020.

The final internal artifact set is approved only when its generated release
manifest contains the tagged commit, SHA-256 values, clean-environment wheel
smoke result, and a current real CATIA validation record.

## Known boundaries

Public PyPI, a standalone executable, parameter `sweep`, a second CAD backend,
and unlisted CATIA environments are not supported by this preview.
